# 5miles

> 5miles is a hyper-local mobile marketplace for buying and selling used goods — cars, furniture, electronics, fashion, baby and kids items — and for offering local services such as beauty, auto repair and home cleaning. Founded in 2014 in Dallas, Texas by Lucas Lu and acquired by a China-based buyer in 2020, the company runs the 5miles iOS and Android apps, the 5miles.com web marketplace, and the 5miles Dash bidding site.

> API surface: none published. As of 2026-08-05 5miles publishes no developer portal, no API reference,
> no SDKs and no machine-readable specification (OpenAPI, AsyncAPI, GraphQL SDL, Postman). The host
> `api.5miles.com` answers 404 for every discovery path probed and serves the company's own mobile and
> web clients only. This file is generated by API Evangelist from public pages; it is not published by
> 5miles.
